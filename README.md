# LUNA NECO CAFE PUZZLE

[**ゲームを遊ぶ**](https://Lunaneco.github.io/luna-neco-cafe-puzzle/)

ルナネコカフェパズル。スイーツをつなげて消して、60秒でハイスコアを目指すカフェパズルです。

[作者のDreamCore公開版](https://www.dreamcore.gg/game/g_f8Skb5fzlD)のゲームコードと画像・音声を引き継いだ独立版です。DreamCoreのアカウントやサーバー、CDNは必要ありません。画像12点、音声7点、p5.js、フォントをこのリポジトリに収録しています。

## 遊び方

1. 「スタート」を押します。
2. 上下左右につながった同じスイーツを、2個以上まとめてタップ／クリックすると消えます。
3. 消した数の **2乗 × 10点** を獲得。空いた場所には新しいスイーツが落ちてきます。
4. 同じスイーツを10個以上消すと、種類に応じて特殊キャラクターが1個出現します。
5. 特殊キャラクターをタップすると効果が発動します。

| キャラクター | 出現条件（元ゲームの種類番号） | 効果 |
| --- | --- | --- |
| ルナ | type 4 を10個以上 | 残り時間 +10秒 |
| ツキネコ | type 3 を10個以上 | 20秒間、得点が2倍 |
| もち | type 0・1・2 のいずれかを10個以上 | 盤面の通常ブロック1種類をtype 1に変換 |

制限時間切れ、または消せる組み合わせと特殊ブロックがなくなると終了します。オンラインで開始したプレイは、終了後に名前を登録して全国ランキングに参加できます。音は右上の「♪ ON / OFF」で切り替えられます。

タイトル画像と盤面は縦横比を固定し、スマホの表示領域に全体が入る最大サイズへ均等に拡大・縮小します。画面との比率の違いは余白にし、ノッチやホームインジケーターを避けて中央に配置します。向きやブラウザバーによる表示領域の変化にも追従します。タブ切り替え、別アプリへの移動、画面ロック、ページ離脱ではBGM・ボイス・効果音を停止します。戻ったときは、制限時間内のプレイ中に限りBGMだけを続きから再開します。ミュート設定は維持され、離れている間も制限時間は進みます。

**ランキングは全プレイヤー共通です。** タイトル画面の「全国ランキング」で上位100件を確認できます。プレイ終了後、名前（10文字まで）とスコアを公開登録すると自分の全国順位が表示されます。同点は先に登録した記録を上位にします。表示名はニックネームであり、アカウントや本人確認とは紐づきません。

ゲーム本体はGitHub Pages、ランキングAPIとデータベースはCloudflare Workers / D1で運用します。開始時にサーバー発行のプレイ情報を取得し、登録時に操作履歴からスコアを再計算します。同じプレイの再送は二重登録されません。通信失敗時は登録ボタンから再送できます。開始時に接続できない場合は、全国記録に登録されない練習モードで遊べます。

旧ブラウザ内ランキングとDreamCore側の記録は全国ランキングに合算しません。過去のプレイ内容を検証できないため、新たに遊んだ記録から登録します。

日本語・英語・中国語・韓国語・スペイン語・ポルトガル語を引き継いでいます。通常はブラウザの言語を使い、URLの `?lang=ja` / `?lang=en` などで指定できます。

## ローカル起動

Node.js 22以上で、追加パッケージのインストールは不要です。

```sh
npm start
```

表示された `http://127.0.0.1:4173` を開きます。別のポートを使う場合は `PORT=8080 npm start`。HTMLファイルのダブルクリックではなくHTTPサーバーから開いてください。

## 検証・ビルド

```sh
npm run check
npm test
npm run build
npm run preview
```

- `check`: JavaScriptの構文、素材23点のSHA-256、参照ファイルの存在、素材がローカル参照であることと、ランキングAPI以外の外部依存がないことを確認します。
- `test`: 得点・連結判定・特殊効果・制限時間・補充・リトライ・全国ランキング・サーバー検証・二重登録・通信失敗・画面倍率・音声の停止と再開などの回帰テスト。
- `build`: 配信に必要なファイルだけを `dist/` に出力します。
- `preview`: ビルド済みの `dist/` を配信します。

全国ランキングの読み込み・プレイ開始時の記録取得・スコア登録には通信します。画像や音声はすべて同梱です。オフラインでは練習プレイができます。ランキングサーバーの設定・ローカル検証方法は [docs/LEADERBOARD.md](docs/LEADERBOARD.md) を参照してください。

## GitHub Pages

このリポジトリの `main` へのpushで、GitHub Actionsが検証・テスト・ビルド後にPagesへ公開します。

別のリポジトリへ移す場合は、Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。すべての配信パスは相対パスなので、プロジェクト配下のURLにも対応します。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | タイトル・結果画面と6言語の文言 |
| `src/game.js` | 元ゲームを引き継いだゲーム処理・描画・音声 |
| `src/round.js` / `src/leaderboard.js` | 共有のスコア検証ルールとランキングAPIクライアント |
| `server/` | Cloudflare Worker・D1スキーマ・設定 |
| `src/styles.css` | ローカルフォントとレスポンシブ表示 |
| `assets/images/` | タイトル・背景・スイーツ・キャラクターなど12点 |
| `assets/audio/` | BGMとキャラクターボイス7点 |
| `assets/fonts/` | DotGothic16とOFLライセンス |
| `vendor/` | p5.js 1.11.0とライセンス |
| `docs/asset-manifest.json` | 元素材URL、サイズ、SHA-256 |
| `docs/MIGRATION.md` | 移植内容・変更点・検証記録 |
| `tests/` | ネットワーク不要の回帰テスト |
| `.github/workflows/pages.yml` | テストとPages公開 |

素材を意図的に更新した場合は、`docs/asset-manifest.json` の対応するサイズ・ハッシュ・出典も更新してください。
