# DreamCore → GitHub 移植記録

移植元: https://www.dreamcore.gg/game/g_f8Skb5fzlD

実施日: 2026-09-12

## 元のまま引き継いだ内容

- 390 × 844の仮想画面、8列 × 13行、48pxのブロック。
- 60秒の制限時間、上下左右の同種2個以上で消去、個数² × 10の得点。
- 10個以上の消去で種類に応じた特殊キャラクター生成。
- +10秒、20秒の2倍得点、1種類をtype 1へ変える特殊効果。
- 落下と補充、パーティクル、発光・変換アニメーション、手詰まり判定。
- タイトル画像、背景、通常5種、特殊3種、肉球アイコン、未使用キャラクター1点の合計12画像。
- BGM1曲とボイス6本の合計7音源、Web Audioによる効果音。
- 日本語を基準とした6言語、名前入り上位5件の端末内ランキング。
- 元ゲームで使用していたp5.js 1.11.0およびDotGothic16。

元コードに読み込みだけが存在した `character-unused.png` も保全しています。通常プレイでは使われていないため初期ロードから外しています。

## 独立動作のための変更

- DreamCoreのSDK、ランタイム注入、解析・親ページ通信、素材URLリゾルバーを除去。
- すべての素材・フォント・ライブラリをローカル相対パスへ変更。
- HTML・CSS・ゲームJavaScriptを分割し、ビルド・テスト・GitHub Pages公開を追加。
- 再挑戦でDreamCoreへの通知やリロードをせず、ゲーム状態を初期化。
- タイトル画像の実際の縦横比を使用し、タイトル文字とキャラクターの左右が切れる表示を修正。
- スマホの動的表示領域への対応、結果パネルのスクロール、HUDの横幅調整。
- ミュート、ボタンのキーボード操作、名前入力のEnter送信を追加。
- 保存領域が利用できない環境でも起動できるようにし、不正な保存形式を検証。
- 名前をHTMLとして解釈せず文字列で表示し、ランキングへの重複登録を防止。
- フレーム更新前でも制限時間を超えたタップを拒否。
- 音声機能が使えない環境のフォールバックと、リトライ・終了時のボイス停止。

## サービスの境界

ゲーム内のランキングは端末・ブラウザ内に保存します。DreamCoreの共通ランキング、認証、コメント、スタンプ、ブックマークは元サービスの機能であり、GitHub Pagesの静的配信には含めません。元サイトの過去スコアは異なる配信元のため自動では引き継がれません。

ゲームは元コードにある常時補充のルールを維持しています。元コードに残る「パーフェクト」表示用の分岐に新しいクリア条件は追加していません。

## 2026-09-12: 初期倍率とバックグラウンド音声の修正

- タイトルは基準幅390pxを上限とし、元画像の1050:1690の縦横比を固定。
- 盤面は390 × 844を100%とし、画面が狭い場合だけ同じ倍率で縦横を縮小。
- `visibilitychange` / `blur` / `pagehide` でBGM・ボイス・Web Audioの効果音と再生待ちタイマーを停止。
- フォーカスと可視状態の両方が戻った場合のみ、進行中かつ時間内のBGMを続きから再開。ミュート設定を維持し、古いボイスや効果音は再生しない。
- 28件の回帰テストでイベント順序・音声再生の遅延完了・時間切れ・倍率を確認。
- 実ブラウザで1440 × 1100の等倍表示、320 × 568の縦横比維持、フォーカスを外した際の全7音源の停止・ミュート、戻った際のBGMのみの続き再生を確認。
- `tests/audio-focus.html` はブラウザでフォーカス移動を手動検証するローカル用ページ。配信用ビルドには含めない。

APIの仕様: [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) / [Window blur](https://developer.mozilla.org/en-US/docs/Web/API/Window/blur_event)
